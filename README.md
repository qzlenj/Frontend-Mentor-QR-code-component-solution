The goal was to recreate the provided design as closely as possible while practicing responsive layout and Flexbox.

### What I learned

One of the main things I learned from this project was how to make a card responsive.

At first, I had some difficulty figuring out the right card width for different screen sizes. By working through the problem, I learned how `width` and `max-width` can work together to make the card responsive.

I also practiced using Flexbox to center and organize the content inside the card.

### Continued development

I want to continue improving my CSS skills, especially responsive design, Flexbox, and creating layouts that work well across different screen sizes.

## AI Collaboration

I used ChatGPT during this project mainly for reviewing my code, checking my approach, and understanding CSS concepts.

The project itself was built by me, and I used AI as a learning and feedback tool rather than having it write the solution for me.
